三部十九課系統神學裝備 PWA。完全離線可用，長輩友善，永久免費。

國度321空中團契　·　貴格會新埔教會

## 一、部署到 GitHub Pages

1. 在 `spch321-sudo` 帳號下新增 repository，名稱建議 `321theology`
2. 把本資料夾的**全部內容**上傳到 repository 根目錄
3. Settings → Pages → Source 選 `Deploy from a branch` → `main` / `(root)`
4. 幾分鐘後即可開啟：

```
https://spch321-sudo.github.io/321theology/
```

在 iPhone Safari 開啟後，點分享 → 加入主畫面，即成為獨立 App。

## 三、更新內容的流程

內容與程式完全分離。改內容不需要動 `index.html`。

**方式 A｜直接改 JSON**（適合小修正）

1. 編輯 `data/lessons/LXX.json`
2. 把 `sw.js` 第 2 行的 `CACHE_VERSION` 加一號，例如 `g321theo-v1.4.1`
3. 推送到 GitHub

**方式 B｜重新從 Word 轉檔**（適合新增課程或大幅修訂）

1. 把新的 `.docx` 放進 `raw/` 資料夾
2. 在 `tools/convert.js` 的 `FILEMAP` 加入一行：檔名、課程代號、部次、課次
3. 執行 `node tools/convert.js`
4. 同樣要更新 `CACHE_VERSION` 再推送

**每次推送前，一定要更新 `CACHE_VERSION`。** 沒更新的話，使用者的手機會繼續用舊的快取，看不到新內容。

## 四、轉檔腳本的三條重要規則

**規則一：以內文編號為準。**
各課首行的規範說明沿用母指令的舊編號（14-b／15-b／22-b／27／28／29），但內文實際是 11-b／12-b／14｜／16｜／17｜／18｜。腳本一律讀取 `## N｜` 標題的實際編號，忽略首行說明。

**規則二：繁殖卡的 ASCII 框線會被自動解析。**
腳本會把附件三的框線卡片拆成結構化資料（標題、三句話、經文、出處、問題），App 才能畫成圖卡。**新課的繁殖卡請維持現有的框線格式**：`+---+` 分隔、`| 三句話`、`| 一節經文`、`| 一個問題`，且三句話用 `1.` `2.` `3.` 編號。目前十九課全數解析成功。

**規則三：新課請在標題後加標記。**
自第四部（神論）起，建議標題寫成：

```
## 7｜關鍵區分：啟示／默示／光照   [B] [○]
```

`[A]/[B]/[C]` 是三層分辨，`[◎]/[○]/[△]` 是引用可信度。加上之後，人工標記的成本趨近於零。

## 六、v1.1 新增的兩個功能

**繁殖卡工作室**

切到「繁殖卡」深度後，按「做成圖卡，傳給一個人」，App 會用 Canvas 畫出一張 1080px 寬的圖卡：課別色的標題帶、三句話、經文、以及給對方的那個問題。在圖上長按即可存圖或直接分享到 LINE。

圖卡底部固定印著一行小字：**「這張卡的目的是問一個好問題，不是給一篇好答案。」**——這句話是給分享的人自己看的。

**一週後的關懷**

在第八步寫下「要講給誰聽」之後，滿七天，今日頁會出現一張卡：「你在第 N 課寫下要講給某某聽。講了嗎？」

按「還沒」不會被責備，只會把時間往後推一週。連續三次回報還沒，App 會改成顯示第十五課的那段話：

> 不急。耶15:16 為「享受」保留了位置。
> 先讓自己被餵飽，滿出來的自然會流給別人。

## 六之二、v1.2 新增：金句間隔重複

十九課的「本課金句」已全數自動擷取入庫（含經文出處），並補上每課的「本課宣告」。

- **自動加入**：走到第三步「信服」時，該課金句自動進入複習排程。也可在工具頁手動挑選任一課加入。
- **間隔**：1、3、7、16、35、90、180 天。答對往上一階，答錯退一階、明天再見。
- **遮字複習**：隨機遮住約三分之一的字，點「看答案」才顯示全文。同一天看到的空格位置固定，不會每次刷新。
- **朗讀**：在複習畫面按喇叭鍵，會唸出完整經文（不是遮字版）。

**刻意不做的**：沒有答對率、沒有排名、沒有「連續複習幾天」。複習完的畫面寫的是——

> 神的話不是靠記憶力保存的，是靠祂保守的。
> 你今天做的，只是把心再擺回祂的話面前一次。

## 六之三、v1.3 新增：小智、真人語音、畫線、錄音

**AI 神學助教「小智」**

右下角的浮動按鈕。使用既有的 Cloudflare Worker：

```
aiEndpoint : https://xiaozhi-proxy.spch321.workers.dev
aiModel    : claude-sonnet-4-6
```

在課程頁開啟時，App 會把**這一課的學員本全文、核心經文、修正321、三層分辨表、固定結尾語**一併送給小智當背景，所以它回答的是這一課，不是泛泛的神學常識。

系統提示裡寫死了三條戒律：

1. **有據**——回答要指出依據哪一課、哪一節經文，並標明是 A 層、B 層還是 C 層。教材沒處理的就明說。
2. **不定案**——B 層爭議不下定論，公平呈現不同立場。
3. **轉介**——涉及婚姻危機、憂鬱、屬靈權柄的傷害，先關心，並鼓勵與牧者或專業人員談，不假裝專業。

每則回答固定以這一句結尾：**「我可能會錯。請你自己回到聖經查考（徒17:11）。」**

**真人語音**

沿用既有的 Azure Worker：

```
ttsEndpoint : https://azure-tts.spch321.workers.dev
聲音        : 雲哲（zh-TW-YunJheNeural）／雲帆 HD／曉辰 HD
```

作法與晨讀321一致：依標點切成 100–300 字的段落逐段抓取、逐段接續播放，並預抓下一段減少停頓。唸過的段落存進 IndexedDB，**再聽一次完全不需要網路**。iOS 的無聲解鎖序列也一併移植了。

**任何一段抓不到，就用系統內建語音把那一段補上，絕不中斷。** 沒有網路時整段自動走系統語音。

**畫線與註記**

在課文上選取一段文字，會跳出工具列：畫線／畫線＋筆記／朗讀／問小智。

畫線用的是「去空白字元索引」比對，所以**可以跨越粗體、經文連結等標籤**，不會因為選到一半有個 `<strong>` 就失敗。有註記的線會多一個 ✎ 記號，顏色也不同。所有畫線列在課程頁下方，點一下可以編輯、朗讀、問小智或刪除。

**語音筆記**

課程頁可直接錄音：講道、小組分享，或自己講一次給自己聽（這正是第八步「繁殖」的預演）。錄音存在 IndexedDB，**只留在這台手機**，可播放、可刪除。

## 六之四、v1.4：品牌圖示

採用 321 標誌作為 App 圖示——三個相扣的圓（3 聖靈的鴿子、2 屬靈同伴、1 聖經），中心是十字架，底下托著一本敞開的聖經。

產出五個檔案：

| 檔案 | 用途 |
| --- | --- |
| `icon-192.png` / `icon-512.png` | iPhone 主畫面、瀏覽器分頁 |
| `icon-mask-192.png` / `icon-mask-512.png` | Android 適應性圖示（內容縮至 80% 安全區，避免被裁到） |
| `logo.png` | 啟動畫面與「關於」卡片 |

原圖四周有白邊，直接當圖示會在 iPhone 圓角外露出一圈白框，所以已裁去外圈 3.5%，並以深綠 `#174238` 補滿背景。

**啟動畫面**：開啟 App 時先顯示深綠底的標誌，資料載入完成後淡出。`theme_color` 與 `background_color` 也一併改為 `#174238`，讓狀態列、啟動畫面與圖示連成一氣。

**課程內的三部配色維持不變**——第一部深藍、第二部深綠、第三部赭金。品牌色只用在「進入 App 之前」，不干擾課文的辨識系統。

## 七、設計上的三條戒律

這三條寫在企劃書第 4.3 節，程式裡確實照做了，改版時請不要拿掉：

1. **不製造比較**　沒有排行榜、沒有公開進度、沒有「你比多少人認真」。
2. **不製造焦慮**　不用連續天數斷鏈懲罰。只顯示累積，不顯示斷裂。
3. **不製造依賴**　每課的「固定結尾語」強制顯示，不可略過：
   **若有一天你在聖經裡看見與本課不同的亮光，請跟隨聖經，不要跟隨我們。**

## 八、隱私

- 所有資料只存在使用者自己的手機（localStorage），不上傳任何伺服器。
- 繁殖對象的名字、個人筆記、學習進度，永遠留在本機。
- 換手機前，請到「我的 → 備份 → 匯出備份」。
